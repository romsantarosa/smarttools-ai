⏱️  5 MINUTOS PARA COMEÇAR

───────────────────────────────────────────────────────────────────────────────
PASSO 1: API KEY (1 minuto)
───────────────────────────────────────────────────────────────────────────────

1. Acesse: https://makersuite.google.com/app/apikey
2. Clique: "Create API Key"
3. Copie a chave


───────────────────────────────────────────────────────────────────────────────
PASSO 2: CONFIGURAR (2 minutos)
───────────────────────────────────────────────────────────────────────────────

1. Copie o arquivo de exemplo:
   $ cp .env.local.example .env.local

2. Edite .env.local e adicione sua chave:
   VITE_GEMINI_API_KEY=sua_chave_aqui

3. Salve o arquivo


───────────────────────────────────────────────────────────────────────────────
PASSO 3: TESTAR (2 minutos)
───────────────────────────────────────────────────────────────────────────────

1. Inicie o dev server:
   $ npm run dev

2. Abra no navegador (normalmente http://localhost:5173)

3. Navegue para: PLANEJAMENTO SPLIT

4. Arraste um PDF (normal ou scaneado)

5. Clique em: ANALISAR SPLIT

6. Pronto! ✅

❌ ALGO NÃO FUNCIONOU?

─────────────────────────────────────────────────────────────────────────────

Problema: "API Key não configurada"
├─ Verifique se criou .env.local
├─ Verifique se o arquivo tem:
│  VITE_GEMINI_API_KEY=sua_chave_aqui
└─ Se mudou .env.local, reinicie: npm run dev

Problema: "Gemini API error 403"
├─ Regenere a API key em:
│  https://makersuite.google.com/app/apikey
└─ Copie a NOVA chave para .env.local

Problema: "PDF.js worker error"
├─ Reinicie o dev server:
│  npm run dev
└─ Limpe cache se necessário:
   rm -rf node_modules/.vite && npm run dev

Problema: "OCR muito lento"
├─ PDFs grandes levam mais tempo (1-5 minutos para 50+ páginas)
├─ Verifique sua conexão de internet
└─ Ou limite a 20 páginas por upload
